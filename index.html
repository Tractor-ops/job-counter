Job Counter

Android application for agricultural task recording

Job Counter is an Android tablet application designed to record agricultural drainage work using John Deere machine location data.

The application records named jobs, their location and the number of Small, Medium and Large tasks completed at each job location.

John Deere Integration

Job Counter integrates with authorised John Deere Operations Center data to identify equipment and obtain machine location information.

Privacy

John Deere information is accessed only after the user authorises access to their Operations Center organisation.
